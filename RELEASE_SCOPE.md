# Release scope

Prepared on 2026-08-06 from the immutable r21 source release inside the
author's validated Core/P2.1 reproduction archive. This GitHub package is
deliberately smaller than the full archive and must not be represented as a
complete data-and-checkpoint release.

It retains source code and selected public evidence but excludes datasets,
weights, private material, build caches, and Git internals. The full archival
base package and the separate LoveDA confirmatory delta remain the authoritative
sources for exact audit artifacts.
